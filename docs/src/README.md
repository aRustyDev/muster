# Orrery / Muster — documentation

Architecture and decision records for the Orrery feasibility engine, the
Muster application, and the Muster-SDK search layer.

* Decision records (MADR): the chapters listed in the sidebar. ADR-0015
  (datastore) is `proposed` and open; the funnel that closes it is ADR-0021.
* Plans, specs, PRDs, questions, and research live in `.claude/plans/` in
  the repository, referenced from the ADRs by number.
* The benchmark evidence behind the datastore analysis is reproducible via
  `./evidence/run_all.sh` at the repository root.
